# Screenshots Guide

Para manter a estética do repositório, siga estas instruções ao capturar as screenshots:

1.  **Resolução:** Recomendada 1920x1080 (16:9) ou aspecto similar para manter a consistência.
2.  **`desktop.png`**: Mostre o desktop limpo com o wallpaper, a barra do GlazeWM (Zebar) visível e talvez o Neofetch/Fastfetch rodando em um terminal translúcido centralizado.
3.  **`terminal.png`**: Foque no WezTerm executando alguma ferramenta visual como `btop`, `yazi` ou listando arquivos com `eza`. Mostre o esquema de cores.
4.  **`browser.png`**: Mostre o Zen Browser aberto com o tema Nebula. Abra uma página limpa ou o próprio GitHub do repositório.
5.  **`editor.png`**: Neovim aberto com algum código de exemplo. Divida a tela para mostrar explorador de arquivos de um lado e código do outro para evidenciar os plugins.
6.  **Formato:** Salve como `.png`.
7.  **Substituição:** Substitua os placeholders presentes na pasta e rode o `git add assets/screenshots` para atualizar no repositório.
