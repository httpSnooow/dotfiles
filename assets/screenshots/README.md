# Screenshots

Para adicionar screenshots ao README, tire os prints e coloque nesta pasta com os nomes:

- `desktop.png`     — desktop limpo, sem janelas abertas, wallpaper à mostra
- `terminal.png`    — WezTerm com Starship prompt + Fastfetch rodando
- `tiling.png`      — GlazeWM com 3-4 janelas em tiling layout
- `browser.png`     — Zen Browser com tema Nebula, mostrando a customização
- `editor.png`      — VSCode ou Neovim com código aberto

Resolução recomendada: 1920×1080 ou maior.
Crop e compressão: use `magick screenshot.png -resize 1920x -quality 85 screenshot.png`
